# Test Plan - SauceDemo

## Project Overview

This repository contains the Test Plan for the SauceDemo web application. The test plan defines the objectives, scope, strategy, environment, and processes used to evaluate the functionality, stability, and performance of the application.

## System Under Test

SauceDemo -> https://www.saucedemo.com/

## Testing Objectives

- Verify application behavior with valid and invalid inputs

- Identify and document defects with supporting evidence

- Validate role-based functionality across supported user types

- Assess application response time and workflow stability

## Test Plan Components

The test plan is structured into the following main components:

- Objectives & Scope

- Test Strategy & Design

- Test Environment and Tools

- Entry/Exit Criteria

- Schedule & Resources & Assumptions

- Defect Management Process

- Metrics and Reporting

- Risks & Mitigation

## Test Strategy Covered

Testing is conducted using both manual and automated approaches. Unit, integration, and system testing levels are applied to ensure feature correctness and end-to-end workflow validation.
