# Bug Reports - Sauce Demo

## Overview

This document provides a consolidated overview of the defects identified during the execution of test cases on the **Sauce Demo (Swag Labs)** website.

The reported issues were extracted directly from functional test case execution and documented to support analysis.

## Scope of Bug Reporting

Bug reports included in this repository cover issues related to:

- Verify Checkout with Empty Cart.

- Verify Checkout - Last Name Field Validation.

- Verify Login Attempt with Locked User.

- Product filtering and sorting

- Verify Item's Price Stability.

- Items' Correct Images/ Item's correct description.

- Add to cart / Remove from cart.

## Bug Identification Process

Bugs were identified during functional testing by comparing \*\*expected results\*\* with \*\*actual results\*\* for each executed test case.

Whenever a deviation was observed, a bug report was created and linked to its corresponding test case.

## Bug Report Structure
Each bug report includes the following information:

## 1. Bug ID
- **ID:** BUG-XX  
- **Name:** Short descriptive title of the bug  
- **Reporter:** Hala Hanaqtah  
- **Submit Date:** YYYY-MM-DD

## 2. Bug Overview
- **Summary:** Brief explanation of the bug  
- **Screenshot:** (Attach screenshot if available)  
- **URL:** https://www.saucedemo.com/

## 3. Environment
- **Platform:** Web Application  
- **OS:** Windows 
- **Browser:** Chrome 

## 4. Bug Details
- **Description:** Detailed description of the bug  
- **Steps to Reproduce:**  
  1. Step one  
  2. Step two  
  3. Step three  
- **Expected Result:** What should happen  
- **Actual Result:** What actually happens

## 5. Bug Tracking
- **Priority:** Low / Medium / High  
- **Severity:** Low / Medium / High 

## 6. Notes
Additional information, observations, or context (optional)
